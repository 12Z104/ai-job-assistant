## 一、超级简历 WonderCV（[wondercv.com](https://wondercv.com) / [chaojijianli.com](https://chaojijianli.com)）



* **目标人群**：中文求职者为主，覆盖校招到社招，应届生 / 互联网 / 金融 / 咨询 / 快消等行业均有模板；中英文简历都做。**已查证**（官网首页 [https://www.wondercv.com/](https://www.wondercv.com/) ）。

* **核心功能（对照四环节）**：


  * 简历 ×JD 匹配：**部分覆盖**。官网称 "基于 160 万字行业语料库，AI 解析岗位 JD 自动匹配 5,000+ 专业表达模型"，做 "岗位关键词密度检测｜竞争力措辞优化｜ATS 兼容性校准"—— 是 JD 驱动的内容优化，但未见独立的 "匹配打分 / 评分报告" 环节。**一方称**（官网 [https://www.wondercv.com/?cgv=6jgemg9emy](https://www.wondercv.com/?cgv=6jgemg9emy) ）。

  * 针对性改写：**覆盖**。AI 一键生成、智能诊断、智能检查。**已查证**。

  * 模拟面试：**不覆盖自助 AI 对话**。官网 "服务" 页提供人工 "面试辅导"" 导师辅导 " 服务（¥189 起 / ¥199 起），是真人导师 1v1，不是多轮 AI 对话模拟面试。**已查证**（[https://m.wondercv.com/mcv/pages/service/index/](https://m.wondercv.com/mcv/pages/service/index/) ）。

  * 导出 PDF：**覆盖**，会员权益含不限次数下载。**已查证**。

* **AI 实现方式**：官网自述 "AI 基于海量真实通过筛选的简历训练，按 HR 评估标准生成和优化内容"，未公开具体模型名称；支持中文简历一键翻译英文。**一方称**。

* **商业模式与定价**：会员订阅制。官方 buy\_member 页（[https://www.wondercv.com/account/users/buy\_member](https://www.wondercv.com/account/users/buy_member) ）只展示权益不展示价格（价格在登录墙后）。第三方评测口径（棱镜简历，2026-07-03 核实）：VIP 约 ¥18 / 月、¥45 / 季、¥78 / 年、¥98 终身（另有 ¥128 终身 PLUS）；免费额度为每天 1 次 AI 诊断 + 1 次英文翻译；免费 PDF 导出需模板 / 颜色 / 字段全部默认，入口较深。人工简历优化 / 面试辅导 ¥189 起。**转述**（[https://prismresume.cn/compare/wondercv](https://prismresume.cn/compare/wondercv) ）。

* **平台形态**：Web 为主，有移动端 H5（[m.wondercv.com](https://m.wondercv.com)）。**已查证**。

* **与本项目差异点（一句话）**：超级简历强在 "模板 + AI 生成 / 诊断 + 人工导师服务"，但**没有自助式简历 ×JD 结构化打分，也没有多轮 AI 模拟面试**—— 人工面试辅导是付费真人服务，不是闭环里的第④步。

## 关键结论（供本项目定位参照）



1. **"简历 ×JD 结构化打分 + 改写前后高亮" 这一环节，国内几乎没有产品做成独立主线**：超级简历 / 锤子 / 职徒 / 知页的 AI 都是 "生成整份 + 通用诊断"，不要求用户粘贴具体 JD；招聘平台（BOSS / 智联 / 猎聘）虽做 JD 匹配，但匹配结果是 "岗位推荐" 而非 "针对这一份 JD 给简历打分 + 定向改写"。这是本项目最大的差异化空间。

2. **模拟面试赛道已较拥挤**：牛客 NowGPT（技术岗最强）、BOSS 直闪闪 / AI 模拟面试、智联职悟空、猎聘 Doris、应届生无忧智面都已上线，且多免费或低价。本项目第④步需在 "技术实习场景 + 与前面改写过的简历 / JD 联动" 上做出差异。

3. **游客模式 + 本地多份简历存储 + 不做账号 / 社区 / 支付** 是所有列出产品都没有的 —— 它们全部强绑定账号体系和招聘生态。这是本项目明确的空白点。

4. **后端成本参照**：全民简历开放平台价（AI 优化 1 元 / 份、诊断 1 元 / 次、单条改写 0.2 元、PDF 生成 2 元 / 次）可作为本项目 SSE 后端调用 LLM 的单位成本估算锚点。
